# Fantasy Workshop 双角色一致性圣经

本文件是角色插画、UI 文案与页面分工的固定基准。外观优先级依次为：项目原始参考图、已确认设定表、本文件。任何网页插画不得重新设计发型、帽子、服装轮廓或核心饰品。

## 统一画面锚点

clean simplified hand-drawn anime illustration, thin warm dark-brown lineart, long confident contour lines, large clean shapes, minimal interior lines, soft transparent watercolor coloring, low saturation, mist blue, warm ivory, dusty lavender and navy gray, minimal secondary shadows, subtle off-white paper texture, gentle Japanese fantasy storybook character design, clean readable silhouette, suitable for website UI decoration.

统一排除：photorealism、3D render、高饱和、霓虹、复杂场景、战斗姿势、武器强调、重甲、繁复蕾丝、密集饰品、文字、水印、裁切头部或手部、额外手指、重复肢体、夸张表情、性暗示、母女构图、主仆构图与恋爱宣传构图。

## Noval / 诺瓦尔 / Morning Scribe

- 原始参考：`public/images/apprentice.png`
- 固定外观：银白/象牙白轻盈蓬松侧束发，白花发饰，淡蓝灰眼睛；暖白、雾蓝与浅灰旅行服；花形披风扣、编绳和蓝色水晶。
- 身份气质：来自另一个世界的白发见习修士与旅行者。不能画成高级神职人员、圣甲骑士或严肃禁欲角色。
- 性格基线：明亮、好奇、主动、乐观，面对未知会靠近观察、指向发现、询问并记录。
- 与伊登相处：会自然靠近、依赖和撒娇，但仍能独立行动并主动帮助旅途。
- UI 职责：首页欢迎、文章编辑、灵感、新建、导入、创作进度、自动保存、空白文档与日常提示。
- 关键词：晨雾、纸张、白花、水晶、旅行手记、羽毛笔、发现、记录、柔光。

## Eden / 伊登 / Night Archivist

- 原始参考：`public/images/moon-witch.png`
- 固定外观：身形小巧的年轻成年灰色魔女；银灰长发、灰蓝眼睛；宽大柔软的深蓝灰月星魔女帽、灰紫蝴蝶结、分层暖白长袍与深蓝灰披风。
- 身份气质：森林魔女、旅行伙伴、可靠的日常与资料管理者。不能画成幼童、战斗魔法少女或笨拙的可爱摆件。
- 性格基线：安静、克制、可靠；常见反应是中性、轻微微笑、无奈、专注、轻微担心和完成工作后的放松。
- 与诺瓦尔相处：面对拥抱会短暂僵住或略显无语，但通常继续手上的事，不粗暴推开，也不突然变成夸张傲娇。
- UI 职责：图片库、搜索、档案、设定、收藏、图片集、展览、高级工具、备份、检查与素材整理。
- 关键词：星夜、档案、符文、魔法书、相册、画框、收纳、可靠、森林、灰色魔法。

## 双人关系

- 两人是共同旅行、能力互补的平等伙伴。
- 动势：诺瓦尔更外向、更明亮、更主动；伊登更安静、更稳定、更可靠。
- 亲密感来自长期同行与自然信任，不采用亲吻、床铺、过度脸红、身体暴露或恋爱宣传构图。
- 禁止母女、主仆、老师与幼童、敌对、单向嫌弃、战斗小队和偶像组合表达。

## 页面分工

- `noval`：创作、文章、灵感、日常记录、角色与服装设定。
- `eden`：图片、搜索、档案、世界观、魔法、时间线、收藏与展览。
- `balanced`：主页、项目、总览、备份与完成提示。
- 正常高信息密度状态不显示大人物；人物只服务于 Hero、空状态、首次引导或低频成功反馈。
- 每页最多一处主要人物插画。专注模式始终隐藏人物与纹样。

## 一致性验收

每次生成后逐项检查：发型与发饰、眼睛颜色、固定服装层次、关键饰品、人物比例、手指与肢体、表情强度、页面朝向、角色职责、双人关系语义。任一固定项变化时不得进入资产注册表的 `generated: true` 状态。
