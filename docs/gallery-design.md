# 拾光画廊 · 晨花与星藏

本轮将 `/archive-gallery` 的中性图片网格设计为诺瓦尔与伊登共同旅行中的收藏空间。人物造型沿用 `character-bible.md` 与现有已确认插画。

## 人物与元素

| 来源 | 视觉元素 | 页面位置 |
| --- | --- | --- |
| 诺瓦尔 | 暖白纸张、雾蓝、五瓣白花、缎带、水晶 | 晨光主题、同行徽记、收藏入口、空画框吊饰 |
| 伊登 | 深蓝灰、灰紫、旧金、月牙、星轨、相册画框 | 星夜主题、页头拱窗、图片详情与预览 |
| 同行关系 | 白花与弯月相叠、共同的旅行收藏 | 标题徽记与「晨花记下相遇 · 星夜妥善珍藏」文案 |

每种氛围只在页头显示一处主要人物插画。画廊使用独立生成的专属立绘：晨光为 `public/assets/gallery/noval-gallery-portrait.png`，星夜为 `public/assets/gallery/eden-gallery-portrait.png`。诺瓦尔双手展示风景画片，伊登将画片收进相册；服装、发型与核心饰品依据既有角色设定表。诺瓦尔按反馈仅调整瞳孔视线，使其看向观众，保持原本的低头角度；伊登沿用已确认生成版本。

立绘通过内置 `image_gen` 生成，保留 PNG 的透明通道。完整生成提示记录在 `docs/gallery-evidence/portrait-prompts.json`，瞳孔调整提示见同目录的 `noval-gaze-edit-prompt.txt`。人物本体以轻微轮廓柔化、低透明度模糊副层和底部渐隐融入页面，脸部与手部保持清晰；背景拱窗也在上下边缘渐隐，避免硬切线。

## 色彩与布局

晨光以 `#f6f3ec` 暖纸白、`#354454` 深蓝文字、`#516c82` 雾蓝按钮与 `#91764b` 旧金点缀为主。星夜使用 `#1d2736` 蓝灰底色、`#f0eade` 暖白文字与 `#c7b68f` 浅金按钮，辅以克制的灰紫背景。

中文标题与藏品名称沿用项目衬线字体，操作与数字使用无衬线字体。桌面为图片网格与右侧画中一页；窄屏将详情排到图片下方。页头保留明确的返回地图入口，隐藏此页面重复的浮动返回按钮，避免遮挡藏品操作。

## 原创 SVG

- `public/assets/gallery/companions-seal.svg`：白花、月牙与星点组成的同行徽记。
- `public/assets/gallery/celestial-arch.svg`：双线拱窗、星轨与月饰，作为人物背景。
- `public/assets/gallery/crystal-ribbon.svg`：来自诺瓦尔配饰的缎带水晶，用于空状态。

图形为可独立复用的矢量素材；装饰图像使用空替代文字，不增加屏幕阅读器噪声。

## 交互

- 晨光／星夜切换同时改变主题与人物，偏好保存在本地 IndexedDB。
- 点击图片进入大图；支持左右按钮和方向键循环浏览，Escape 关闭，并将焦点还给打开大图的控件。
- 使用原生模态 dialog 隔离背景操作，大图打开时锁定页面滚动。
- 图片网格使用现有缩略图，大图读取原图；Blob URL 在卸载或切换时释放。
- 保留批量导入、图片详情和移出画廊。移出仅更改画廊成员列表，原图仍在素材库中。
- 尊重减少动态效果设置，不启用持续的装饰动画。

## 验证

`npm run build` 与画廊定向 ESLint 通过。`scripts/verify-gallery.cjs` 使用独立临时浏览器上下文，验证空状态、主题持久化、批量导入、刷新后成员保留、大图翻页与焦点恢复、移出后原图保留，以及 1440、768、390、320 像素视口和减少动态效果。截图使用测试导入的项目素材，未写入用户浏览器的数据。

预览见 `docs/gallery-evidence/`，验证结果见 `verification.json`。浏览器检查基于本机 Chromium；未进行实体移动设备测试。
