# 分类元素与主标志 · 2026-10-04

本轮在还原点 `15e10fc` 上继续修改；主页布局保持现状。

## 独立分类元素

工作区卡片右侧使用专门绘制的 SVG，每个内容类型拥有独立轮廓，不再按两组复用花与月。相同类型的卡片使用相同标签，以便识别。

| 类型 | 专属元素 |
| --- | --- |
| 文章 | 羽笔与书写横线 |
| 图片 | 取景框、山形与光点 |
| 图片集 | 扇形叠片 |
| 设定卡 | 包裹晶石的身份徽章 |
| 合集 | 展开的书页与书签 |
| 时间线 | 弯曲路径、节点与方向箭头 |
| 灵感 | 火种与放射光线 |
| 展览 | 展陈框与基座 |
| 旧版项目类型 | 装订计划板（兼容保留） |

统一线宽、尺寸与低饱和配色；图案仅作类型辅助，中文类型文字继续保留。装饰不接受焦点、不拦截点击。

## 主标志

重新绘制为浅紫月弧、直立蓝晶石与金色星芒。晶石左右对称，内部切面共轴；月弧使用有厚度的轮廓，小尺寸下比多条细轨道更容易辨认。沿用现有品牌文字与字体。
