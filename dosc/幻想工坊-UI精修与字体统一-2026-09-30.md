# 幻想工坊 UI 精修与字体统一

日期：2026-09-30。依据用户提供的书籍页面截图继续改造。代码已修改并验证，未提交或部署。此记录更新 2026-09-29 方案中功能界面混用衬线/无衬线字体的决定。

## 本轮修正

### 字体与排版

- 在 `app/study.css` 定义统一字体变量 `--font-workshop`，功能界面统一使用 `Microsoft YaHei UI / Microsoft YaHei / PingFang SC / Noto Sans SC / system-ui` 字体栈。
- `AppShell` 内标题、按钮、列表、说明及阅读界面使用同一字体家族，通过字号、字重和间距建立层级；代码块维持等宽字体。未下载字体或引入外部字体请求；不同操作系统使用其可用字体。
- 修复字体变大后顶部导航“展览”被挤压的问题：桌面导航使用内容宽度列，搜索区域自适应。
- 书籍页标题、说明、实际书籍/定稿数量与创建按钮合并到同一个页头，去除旧 PageShell 标题带与下方工具栏分离造成的断层。

### 页面与美术

- 新增 `components/content/BookWelcome.tsx`，专门设计空书架状态，替代通用人物空状态与虚线大框。
- 空书架以“让散落的故事，在这里成册”为主文案，包含创建、查看定稿入口与起名/安排章节/收录作品三步引导。
- 绘制内嵌 SVG 书册、纸页、书签、枝叶和星形装饰，结合原有双人插画与拱形底板。新美术为矢量绘制，不是新生成的人物图片。
- 尊重原人物显示偏好；关闭人物后，矢量书册仍构成完整画面，未留下空占位。
- 书架与编订台统一柔和实线、圆角和阴影；书封增加书脊、纸页与材质明暗层次；书籍主操作使用低饱和灰绿，正文保留暖纸底。
- 工作区分类侧栏、搜索、内容卡片和字号同步整理，减少样式混杂。地图与独立拾光画廊的场景美术未重做。

### 动效

- 普通对话框：180ms 淡入 + 小幅位移/缩放；收录抽屉：220ms 侧向入场。
- 按钮增加短暂按压反馈，列表操作在悬停或键盘聚焦时强调。
- 不添加循环人物动画或漂浮粒子；系统 `prefers-reduced-motion` 和应用动态效果偏好可关闭新增动画。

## 验证

- TypeScript、改动文件定向 ESLint、核心 `npm test` 通过。
- `npm run build` 通过。
- 开发模式和生产模式均通过现有书籍浏览器回归：定稿、创建书籍与章节、批量收录、排序、跨章移动、多书引用、只读跳转、取消与焦点恢复。
- 精修脚本通过 320 / 390 / 768 / 1121 / 1440px 页面无横向溢出检查；新建空章节页另测 390 / 1440px。
- 浏览器计算样式确认页面标题、说明、按钮与空状态标题的 font-family 相同。
- 系统减少动态效果时，对话框 animation-name 为 none；关闭人物时矢量场景仍存在。
- 使用独立临时浏览器上下文，不修改用户个人浏览器数据。截图为测试内容。

执行浏览器脚本需要提供 Playwright 与 Edge，可通过 `BASE_URL`（默认 localhost:3101）、`BROWSER_CHANNEL` 调整。当前借用已有运行时依赖，通过 NODE_PATH 临时提供，没有更改依赖清单。
