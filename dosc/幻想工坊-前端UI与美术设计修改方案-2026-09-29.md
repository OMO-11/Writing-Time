# 幻想工坊：前端 UI 与美术设计修改方案

日期：2026-09-29。本文保留已审批的设计方案；审批后的代码实施结果见第 11 节。已在本地实现主要页面改造，未部署上线。配套视觉稿见 [晨雾书房设计板](../docs/design-references/workshop-ui-board-2026-09-29.svg)。设计板为代码绘制的矢量概念稿，示例作品与数量不是真实用户数据。

## 1. 设计主张：晨雾书房

让使用者感到自己在旅途中整理故事、将手稿装订成书。暖纸承载内容，雾蓝组织操作，灰紫标记档案，少量旧金表示定稿。人物出现于欢迎、空状态与低频完成反馈；实际编辑、筛选和目录编排区域保持安静。

继承 `docs/character-bible.md` 的双角色设定及现有 `noval / eden / balanced` 主题。保留主页、雾行图和拾光画廊各自的场景美术，本轮主设计范围是 `/library`、`/projects`、`/workbench`、`/work/[slug]` 和 `/books/[id]`。其他页面仅统一导航、按钮、状态与边距。

使用 ui-ux-pro-max 的可访问性、触控、层级和响应式检查。检索所得通用营销页结构不适合本地写作工具，因此不采用其 Hero + Features + CTA 页面结构；具体方案以当前代码和角色设定为准。

## 2. 当前依据与修改理由

| 当前实现依据 | 设计问题/限制 | 本次设计决定 |
| --- | --- | --- |
| `ContentWorkspace.tsx` 用同一侧栏排列多种内容和已完成作品 | 内容类型与创作阶段混在同一级 | 侧栏分为“创作内容 / 素材与设定 / 定稿档案”；定稿入口独立分隔 |
| 工作区状态筛选有 completed，定稿另由 finalizedAt 标识 | “已完成”容易被误认为不可修改 | 普通 completed 显示“写作完成”；带 finalizedAt 才显示“已定稿 · 只读” |
| `BookProjects.tsx` 顶部同时展示阅读、两种导出、改名、添加章节 | 高频编排和低频管理操作相互竞争 | 阅读为次操作，导出合并菜单，改名进入更多菜单；主操作为“收录作品” |
| 书架已有选择记忆、批量收录及冲突副本 | 功能已具备，但书籍对象的视觉辨识弱 | 增加程序化书封、明确选中态、章节结构和目录保存状态 |
| 创建/重命名仍用原生 prompt，删除与定稿用 confirm | 无法统一输入提示与错误反馈 | 改为可访问对话框，保留原来的事务、校验及不可逆语义 |
| `globals.css` 与 `theme.css` 已有纸张色、角色主题及装饰 | 书籍 CSS 存在单独硬编码色值 | 复用既有 token，逐步收敛同义变量；不另造一套全局主题 |
| 本地 IndexedDB 自动保存 | “已保存”可能被误解为已备份 | 状态统一写“已保存到本机”；备份状态单独表达 |

以上来自源码与资产盘点，配套设计板用于方案表达，不作为现有页面截图或完整视觉审计结果。

## 3. 导航与页面关系

主导航维持“主页 / 创作 / 工作区 / 项目 / 展览”。项目页标题使用“书籍项目”，解释为“把定稿作品编成书”；工作区解释为“整理手稿、素材与设定”。保留旧地址跳转兼容。

```mermaid
flowchart LR
  A[工作区：草稿与资料] --> B[创作工坊]
  B -->|完全保存并确认| C[已完成作品：已定稿 · 只读]
  C -->|收录引用| D[书籍项目：章节与目录]
  D --> E[整书阅读与导出]
  C -->|创建修订草稿| B
```

“完全保存”保持产品现有操作名称，旁边解释“定稿后原文不可修改”。目录编辑不改变原作；同篇定稿可以被不同书籍引用。修订草稿具有新 ID，不自动替换旧书目引用。

## 4. 视觉系统

### 4.1 色彩与材质

| 语义 | 建议值 | 使用位置 |
| --- | --- | --- |
| 页面纸底 | `#F4F0E8` | 沿用 --page-bg |
| 主纸面 | `#FBF8F2` | 正文、表单、目录 |
| 次级纸面 | `#EDE8DF` | 侧栏分组、书架底 |
| 主文字 | `#363D49` | 标题与正文，建议替换偏浅正文 |
| 次文字 | `#626976` | 时间、说明；作为正文同样以 4.5:1 为目标 |
| 操作雾蓝 | `#526680` | 主按钮、选中边线、焦点 |
| 雾蓝底 | `#E4EAF1` | 选中项底色 |
| 档案灰紫 | `#695C79` | 伊登主题标签、资料类别 |
| 定稿旧金 | `#786139` / `#F0E7D3` | 深金字 + 浅金底，附锁图标 |
| 成功 / 风险 | `#416957` / `#963F43` | 保存成功、失败与破坏性按钮 |

这些是拟采用值，接入时计算所有前景/背景组合的对比度。浅金、淡蓝只作装饰，不直接作为白底小字。不可只用颜色区分草稿、定稿或保存失败。

纸纹只用于页面外围与空状态插画背景，不覆盖正文、输入框或列表文字。装饰纹样透明度建议 3%–5%，最大一处；取消高密度噪点和整页持续漂浮粒子。

### 4.2 字体、尺寸和几何

界面使用现有无衬线字体栈；阅读与大标题使用现有宋体/衬线栈。中文优先系统可用字体，首轮不添加外部字体网络请求。

| 项目 | 桌面 | 手机 |
| --- | --- | --- |
| 页面标题 | 30px / 1.3 | 24px / 1.35 |
| 分区标题 | 20px / 1.4 | 18px / 1.45 |
| 操作及表单 | 14–16px / 1.5 | 16px / 1.5 |
| 元信息 | 13px / 1.6 | 13px / 1.6 |
| 阅读正文 | 18px / 1.9 | 17px / 1.9 |

采用 4 / 8 / 12 / 16 / 24 / 32 / 48px 间距；控件圆角 8px、卡片 12px、对话框 16px。章节不再一层层包裹大圆角卡片，以细分隔线建立秩序。操作图标沿用 Lucide，18–20px、统一线宽；装饰符号使用既有 SVG。

## 5. 逐页设计

### 5.1 工作区：手稿与档案桌

桌面外边距 32px，主容器最大 1440px；左栏 208px，中间间距 24px，内容自适应。页头只保留标题、说明和“创建内容”主按钮；搜索、状态和排序位于列表工具栏。

左栏第一组“全部内容 / 文章 / 笔记”，第二组沿用已有设定、图片、合集等内容类型，第三组独立“已完成作品”。不要为了重新分组增删已有 ContentType。数量使用小字，选中项显示左侧蓝线、底色与 aria-current/选中语义。

卡片顺序固定：内容类型与状态 → 标题 → 两行摘要 → 标签与更新时间。标题最多两行，完整名称仍可通过详情获得。封面仅在确有图片的内容中出现；文章不自动添加与正文无关的风景。

已完成作品分区页头显示锁标识及“原稿只读，可创建修订草稿或收录到书籍”。卡片主动作“阅读”，次动作“收录到书籍”。后者是待接入的新入口，复用书籍收录事务，目标为空时引导创建书籍和章节。

空工作区：复用伊登档案插画，按钮“创建第一篇作品”。搜索无结果：小型线框文件图标及“清除筛选”，不使用大人物。加载显示固定高度骨架；读取失败显示“读取失败，重试”，不能当作空库。

### 5.2 书籍项目：书架与编订台（首要改造页面）

桌面基础双栏：书架 248px + 编订区 minmax(0, 1fr)，间距 24px。页面顶部最多 120px 高，双人插画仅用于无书籍空状态，已有目录时不占首屏。

书架条目包含 2:3 小书封、书名、章数/篇数和更新时间。首轮书封由 CSS 配色、SVG 角花和真实文字生成，以稳定 book.id 映射 3 种皮色；不需要先改数据库。自定义封面、简介、作者字段属于后续数据模型扩展，不能只画出可点击入口。

编订区顶部：书名 + 已保存到本机；第二行“整书阅读 / 导出 / 更多”。目录工具栏突出“收录作品”和“添加章节”。导出菜单明确“离线 HTML / Markdown ZIP”，保留已有实现。

章节结构：编号 + 章节标题 + 篇数 + 更多菜单；展开后作品行显示位置、标题、只读标识和操作菜单。保留显式上移/下移、移到章节、移出目录，不把拖拽当作唯一方式。空章节提供“收录作品”入口。

“收录作品”打开右侧 400px 抽屉：搜索 → 目标章节 → 候选列表 → 固定操作底栏。底栏显示“已选 N 篇”，主按钮“收录到章节”。搜索隐藏已选项时提示“其中 N 篇不在当前结果”；可切到“仅看已选”，按选择顺序排列。保留当前跨搜索选择和去重逻辑。

关闭抽屉前若有未收录选择，提示保留/放弃；提交期间禁止重复提交。成功后保留当前章节位置，短暂高亮新条目；失败保留选择并在底栏附近显示错误。并发冲突另存副本时，显示“已另存冲突副本”并给出打开副本入口，不能只报普通保存失败。

修改书名：含可见标签、空白校验、取消和保存的对话框。移除章节：显示章名和条目数，文案“仅移除目录条目，原作品保留”。定稿原作没有删除/编辑入口。

### 5.3 创作工坊：持续书写优先

保留现有编辑、分屏、预览模式。桌面顶栏只占一行，标题、保存状态及模式切换清楚分组。自动保存信息使用“正在保存 / 已保存到本机 / 保存失败，重试”，与定稿分离。

“完全保存”作为工具栏次级描边按钮，点击后展示专用确认框：作品标题、不可修改的范围、可创建修订草稿、仍需备份。主按钮“确认完全保存”，取消保持编辑；等待普通保存完成后才能进入定稿事务。定稿完成提供“阅读作品 / 前往已完成作品”，不模拟出版或上传成功。

人物只在首次空白编辑状态出现，已有正文后收起；专注模式隐藏全局导航以外的非必要装饰，始终提供退出专注按钮。正文区域保留纯色纸面，不以画布纹理作为输入背景。

### 5.4 作品与整书阅读

正文最大 760px；宽屏目录 220px，间距 40px。手机以“目录”按钮打开抽屉，章节和作品锚点独立显示。顶部书名、章数和导出不挤占阅读宽度。

定稿页用一条紧凑状态栏“已定稿 · 只读”，右侧“创建修订草稿”；整书页显示“返回编订”。阅读器的翻页/滚动位置记忆沿用当前功能，不新增假进度。插图只显示作品实际资源，不自动填充场景图。

## 6. 响应式与交互规则

| 宽度 | 布局 |
| --- | --- |
| ≥1280px | 完整书架与目录；收录抽屉覆盖右侧，背景不可操作 |
| 768–1279px | 左栏缩至 200px，目录动作合并菜单；避免强行三栏 |
| <768px | 书架改为“当前书籍”选择入口；目录单栏；收录抽屉全屏，顶部关闭、底部确认 |

移动页边距 16px，操作目标至少 44×44px，底栏预留 safe-area。长书名、长章节名和长标签允许换行，不撑宽页面。手机输入框字号至少 16px；虚拟键盘打开时确认按钮仍可滚动到达。

所有菜单、抽屉和对话框支持键盘与 Escape，正确设置 dialog/aria-modal、初始焦点、焦点限制及关闭后的焦点恢复。弹层出现时禁止背景滚动；错误用 role=alert，保存反馈用 polite status。动画限定透明度/位移 160–240ms；prefers-reduced-motion 下取消移动效果。定稿成功不自动播放人物动画或声音。

### 可交给美术或图像工具的制作提示

**统一风格：** thin warm dark-brown lineart, simplified fantasy storybook illustration, soft transparent watercolor, warm ivory paper, muted mist blue and dusty lavender, restrained antique gold, clean readable silhouette, minimal secondary shadows, no lettering, no watermark.

**A04：** 一叠已装订的旅行手稿，细雾蓝丝带、小封签和一支羽毛笔，三分之四俯视，物件集中画面右侧 60%，左侧留空；柔和晨光，透明背景，完整物件轮廓。封签只有抽象图案，不生成文字；避免真实品牌与复杂背景。

**A05：** 均匀暖白细纤维纸张材质，可无缝平铺，极低对比度，无方向性光照、边框、黑点、文字或明显重复元素；在正文区域禁用。

**A06：** 必须附 `character-sheet.webp` 与现有双人插画作角色参考。两位成年旅行伙伴平等坐在同一侧共同翻阅一本书，诺瓦尔略主动、伊登平静专注，保持原发型、帽子、花饰、披风和饰品；透明背景，头部、手部与帽尖完整，画面周围留 8% 安全边距。禁止重设计角色、幼童化、主仆构图及烘焙 UI 文字。
