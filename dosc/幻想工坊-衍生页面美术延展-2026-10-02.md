# 幻想工坊：书籍衍生页面美术延展

日期：2026-10-02

## 设计方向

延续原创扉页构图，移除空书架纹章下的角色名字与元素说明。诺瓦尔的白花、晶石与伊登的月弧、星迹以细线纹样出现；通过蓝灰与淡紫的细微过渡连接书封、目录和阅读页，不使用人物立绘或无关书本摆设。

## 已实施

- 有书籍的编订页：标题旁的双色装订线、中央花月分隔纹、书架选中状态与微型书封印记。
- 无章节状态：左侧开篇文字与入口、右侧花月线刻，手机上自然折行。
- 已有章节：白花与月弧交替作为章首标记，作品序号、分隔线与章节底色统一。
- 创建书籍、章节编辑及收录弹窗：上缘细线与花月纹，统一标题字重、按钮及选中底色。
- 整书阅读与移动目录：书名页边花月纹、章节题花、细线目录边界。
- 继续采用统一中文无衬线字体，不添加循环动画，装饰 SVG 不进入辅助技术朗读和键盘焦点。

## 素材与实现

`components/ui/FolioOrnament.tsx` 是本次原创 SVG 素材源，提供 paired、flower、moon 三种构图。所有纹样直接随页面渲染，无外部图片请求。书封按现有书籍 ID 稳定选择颜色与纹样。

主要实现位于 BookProjects、BookCover、BookCollectionDrawer、BookReader 与 PaperDialog；样式在 app/projects/projects.css 和 app/study.css。数据结构及书籍操作保持现有实现。

## 验证

- 生产构建（包含 TypeScript 检查）通过；清理了一份损坏的 Next.js 自动生成类型缓存后重新构建。
- 修改组件 ESLint 通过。
- 空书架、新建书籍、统一字体、减少动态效果及 320 / 390 / 768 / 1121 / 1440 五种屏宽检查通过。
- 书籍回归通过：定稿、批量收录、搜索后选择保留、排序、跨章节移动、跨书共享、持久化、只读跳转及移动布局。
- 回归脚本增加修订页导航等待；通过 EVIDENCE_DIR 支持独立截图目录，避免旧截图文件覆盖失败。
